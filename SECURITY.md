# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities via GitHub Security Advisories (Security > Report a vulnerability) or contact [@twojlogin](https://github.com/twojlogin).

## Supported Versions

Only the latest commit on the default branch is supported.

## Guidelines

- Do not disclose publicly before a fix is released.
- Include reproduction details and impact when possible.

Thank you for improving security.
