Szukanie narzedzi

Web (przegladarka)

Otworz /search i wpisz czego szukasz.

Filtry:

  • q — fraza do wyszukania (np. vpn, osint, docker)
  • min_stars — minimalna liczba gwiazdek (0 = wszystkie)
  • alive — 1 = tylko dzialajace linki, 0 = wszystkie

Przyklad: /search?q=vpn&min_stars=100&alive=1

CLI (terminal)

awesome search vpn              # szukaj wsrod 234k narzedzi
awesome search osint            # szukaj narzedzi OSINT
awesome search docker           # szukaj narzedzi do dockera
awesome repos osint             # szukaj repo (awesome lists)
awesome list Security           # lista narzedzi z kategorii Security
awesome top 20                  # top 20 repo wg gwiazdek
awesome random                  # losowe 20 repo

Instalacja / deinstalacja narzedzi

Awesome Tools moze zainstalowac narzedzia direct z GitHuba (git clone).

CLI

awesome install nmap            # klonuje repo do ~/installed/
awesome install tool-name       # dowolne narzadzie z bazy
awesome uninstall nmap          # usuwa zainstalowane
awesome installed               # lista zainstalowanych
awesome check                   # sprawdza czy sa aktualizacje

Web (przegladarka)

Otworz szczegoly narzedzia (/tool/...) — na dole zobaczysz komende instalacji.

Kolekcje

Kolekcje to twoje wlasne listy narzedzi. Mozesz je tworzyc i zarzadzac nimi.

CLI

awesome create moje-osint "Narzedzia OSINT"      # utworz kolekcje
awesome add moje-osint nmap                       # dodaj narzedzie
awesome add moje-osint sqlmap                     # dodaj nastepne
awesome collection moje-osint                     # pokaz zawartosc
awesome collections                               # lista wszystkich kolekcji

Wszystkie komendy CLI

awesome search <query> Szukaj narzedzi wsrod 234k
awesome repos <kategoria> Szukaj repo (awesome lists)
awesome list <kategoria> Lista narzedzi z kategorii
awesome top [n] Top repo wg gwiazdek (domyslnie 10)
awesome random Losowe repo
awesome stats Statystyki bazy
awesome install <tool> Zainstaluj narzedzie (git clone)
awesome uninstall <tool> Odinstaluj narzedzie
awesome installed Lista zainstalowanych narzedzi
awesome check Sprawdz aktualizacje zainstalowanych
awesome validate [n] Waliduj linki GitHub (n=limit, domyslnie 20)
awesome fetch <owner/repo> Pobierz README z GitHub
awesome topic <topic> Pobierz listy z topicem (np. awesome-osint)
awesome rebuild Przebuduj indeks narzedzi
awesome create <name> <desc> Utworz kolekcje
awesome add <collection> <tool> Dodaj narzedzie do kolekcji
awesome collection <name> Pokaz zawartosc kolekcji
awesome collections Lista wszystkich kolekcji
awesome web [port] Uruchom serwer web (domyslnie 5001)

Pobieranie danych

Mozesz pobrac wiecej awesome list z GitHuba:

# Pobierz awesome listy po topic
./download.sh awesome-list          # wszystkie awesome lists
./download.sh awesome-osint         # OSINT
./download.sh awesome-security      # bezpieczenstwo

# Wyciagnij narzedzia z pobranych README
python3 extract_tools.py

# Przebuduj indeks
./awesome rebuild

FAQ

Jak dodac wlasne repo?

Otworz /add i wklej URL z GitHuba (np. https://github.com/user/repo). Narzedzia zostana pobrane automatycznie.

Jak sprawdzic czy link dziala?

awesome validate 50   # sprawdza 50 losowych linkow

Jak zainstalowac narzedzie?

W CLI: awesome install nazwa-narzedzia
W web: otworz szczegoly narzedzia i skopiuj komende.

Gdzie sa zainstalowane narzedzia?

W katalogu ~/installed/ (git clone).

Jak przebudowac baze?

awesome rebuild     # w terminalu

Lub w web: /add -> przycisk "Przebuduj".
