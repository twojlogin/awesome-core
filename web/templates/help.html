Awesome Core — lokalny katalog narzędzi z awesome list

Jeden silnik (SQLite + FTS5), trzy interfejsy: CLI, TUI, Web. Po pobraniu list zero sieci — wszystko działa lokalnie.

Nic nie działa w tle

Żadnych cronów, daemonów ani ukrytych procesów. Odświeżanie uruchamiasz ręcznie — jednym poleceniem albo klikając przycisk na stronie /refresh. Każdy krok wypisuje log i czeka na zakończenie, więc zawsze widzisz, co się stało.

Pierwsze uruchomienie

./awesome refresh        # download → backfill → enrich → build, po kolei
./awesome status         # co jest w bazie i co warto odświeżyć

Kroki pojedynczo: ./download.sh awesome-list 100 1 20 --wide · ./awesome build · ./awesome backfill · ./awesome enrich --limit 20000. Plan bez wykonywania: ./awesome refresh --dry-run.

Wyszukiwanie po ludzku

./awesome search "port scanner" --lang Python --os windows --sort consensus
./awesome search osint --domain security --min-consensus 3
./awesome search "active directory" --limit 30

Filtry: --lang --os --domain --list --min-stars --min-consensus --sort (score, stars, consensus, underrated, gem, name) --alive.

Fasetyki

./awesome langs          # języki narzędzi
./awesome platforms      # windows, WSL, Linux, macOS, Docker, CLI…
./awesome domains        # osint, security, network, devops, reverse-engineering…
./awesome lists          # najlepsze listy wg jakości
./awesome underrated     # dobre narzędzia z małych list
./awesome gems           # ukryte perełki

Skąd ranking

Score to nie gwiazdki listy, tylko: zgoda niezależnych kuratorów (czyli w ilu różnych listach narzędzie występuje), jakość listy, własne gwiazdki narzędzia z GitHub API, żywy link, opis i kompletność metadanych.

./awesome why nmap                 # rozkład punktów
./awesome mentions nmap            # wszystkie listy, w których jest
./awesome info nmap                # szczegóły + komenda instalacji
./awesome list vinta/awesome-python # narzędzia z jednej listy

TUI

./awesome tui

/ szukaj · l język · o platforma · d domena · s sort · g perełki · u niedoceniane · Enter szczegóły · i instalacja · ? pomoc · q wyjście

Dane i eksport

./awesome stats             # co jest w bazie
./awesome validate         # sprawdź martwe linki (--limit N, --non-github)
./awesome export json      # data/tools.json
./awesome export csv       # data/tools.csv
./awesome web 5001         # Flask UI

Limity, o których trzeba wiedzieć

  • Wyszukiwarka GitHuba zwraca maks. 1000 wyników na zapytanie — dlatego download.sh --wide używa kilku zapytań i skaluje wyniki.
  • Prawdziwy język narzędzia znamy tylko tam, gdzie doszedł ./awesome enrich; bez tego lang bywa ?.
  • Linki poza GitHubem sprawdzamy tylko jawnie: ./awesome validate --non-github --limit 500.

Bezpieczeństwo

Sygnały przy repozytoriach (archiwalne, dawno nieaktualizowane) to wskazówki do sprawdzenia, a nie etykieta bezpieczeństwa. Zawsze przejrzyj kod i release'y przed instalacją. Instalacja z weba to wyłącznie `git clone` do katalogu narzędzi — nie jest to terminal.
