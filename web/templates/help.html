Awesome Core — lokalny katalog narzędzi z awesome list

Jeden silnik (SQLite + FTS5), interfejsy: CLI, TUI, Web i MCP dla lokalnych agentów. Po pobraniu list zero sieci — wszystko działa lokalnie.

Nic nie działa w tle

Żadnych cronów, daemonów ani ukrytych procesów. Odświeżanie uruchamiasz ręcznie — jednym poleceniem albo klikając przycisk na stronie /refresh. Każdy krok wypisuje log i czeka na zakończenie.

Pierwsze uruchomienie

./awesome start          # pobierz listy → zbuduj bazę → metadane list
./awesome start --full   # ...plus metadane narzędzi (dłuższe)
./awesome status         # co jest w bazie i co warto odświeżyć
./awesome doctor         # coś nie działa? tu jest odpowiedź

Na Windows: awesome.cmd start. Flaska nie musisz instalować ręcznie — przy pierwszym ./awesome web program przygotowuje środowisko i wypisuje każdy krok.

Wyszukiwanie

./awesome search nmap
./awesome search "port scanner" --lang python --os linux --domain security
./awesome search osint --min-consensus 3 --sort stars

Filtry: --lang --os --domain --list --min-stars --min-consensus --sort score|stars|consensus|underrated|gem|name --alive. Filtry łączą się przez AND.

Zaufanie i bezpieczeństwo danych

./awesome audit
./awesome audit owner/repo
./awesome untrusted
./awesome leaks [--repo] [--readmes] [--no-db] [--pattern REGEX]
./awesome selfcheck

audit wykrywa podejrzane listy/linki (sygnał do ręcznego sprawdzenia, nie skaner malware). untrusted skanuje opisy pod prompt injection. leaks robi lokalny skan możliwych sekretów.

Awesome Core — local catalog of tools from awesome lists

One engine (SQLite + FTS5), four interfaces: CLI, TUI, Web, and MCP for local agents. After downloading lists, everything works locally with zero network.

Nothing runs in the background

No cron jobs, daemons, or hidden processes. Refresh is manual — one command or the button on /refresh. Each step prints logs and waits for completion.

First run

./awesome start          # download lists → build DB → fetch list metadata
./awesome start --full   # ...plus tool metadata (longer)
./awesome status         # database state and what to refresh
./awesome doctor         # diagnose common problems

On Windows: awesome.cmd start. Flask does not need manual install — first ./awesome web bootstraps the environment and prints each step.

Search

./awesome search nmap
./awesome search "port scanner" --lang python --os linux --domain security
./awesome search osint --min-consensus 3 --sort stars

Filters: --lang --os --domain --list --min-stars --min-consensus --sort score|stars|consensus|underrated|gem|name --alive. Filters combine with AND.

Trust and data safety

./awesome audit
./awesome audit owner/repo
./awesome untrusted
./awesome leaks [--repo] [--readmes] [--no-db] [--pattern REGEX]
./awesome selfcheck

audit flags suspicious lists/links (manual-review signal, not a malware scanner). untrusted scans descriptions for prompt injection. leaks performs a local scan for possible secrets.
